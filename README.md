# HAKONE TABLE — 箱根湯本グルメガイド

HTML構造 + CSSデザイン + PHPによる店舗カード生成 + JavaScriptのジャンル絞り込みで構成したレスポンシブなサンプルサイトです。

## 起動方法
PHP 8.x が入った環境で、このフォルダに移動して実行します。

```bash
php -S localhost:8000
```

ブラウザで http://localhost:8000 を開いてください。

## 編集
店舗情報は `index.php` 冒頭の `$spots` 配列から編集できます。デザインは `style.css`、ジャンル絞り込みは `script.js` です。

## 注意
店舗名・紹介文は掲載候補のサンプルです。価格・営業時間・提供内容・営業状況は公開前および訪問前に各店舗の公式情報で確認してください。写真はUnsplashの外部画像URLを使用しています（表示にはインターネット接続が必要です）。
